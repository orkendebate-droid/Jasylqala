# Тесты и тестовые сценарии — Jasylqala

## 1. Автоматические тесты

### Бэкенд (`pytest`)
Запуск:
```powershell
cd backend
.\.venv\Scripts\pytest -v
```
Что проверяется:
- `/health` и справочник из 7 видов деревьев Актау (`/api/species`)
- Создание паспорта дерева и выдача GeoJSON для карты (`/api/trees`, `/api/trees/{id}`)
- Валидация координат (`[-90, 90]`, `[-180, 180]`), высоты (`0..100 м`), состояния (`good`/`fair`/`poor`)
- Загрузка фото: валидное изображение сохраняется, пустые или поддельные файлы отклоняются (`400`)
- Жизненный цикл задач на уход: создание (`pending`) и закрытие (`done`) с фото «до» и «после»
- Распознавание вида по фото (`/api/predict-species`): ровно 3 варианта с вероятностями
- Идемпотентность офлайн-синхронизации (`/api/offline-sync`): повторная отправка с тем же `client_id` не создаёт дубликатов
- Наличие пометки `Демо` (`is_demo=True`) у стартовых демо-деревьев

### Фронтенд (`vitest`)
Запуск:
```powershell
cd frontend
npm test
```
Что проверяется:
- Клиентская нейросеть возвращает топ-3 вида по убыванию вероятности
- Генерация тайлов карты Актау для офлайн-кеша
- Отображение паспорта дерева (бейдж `Демо`, высота, координаты, задачи)
- Сохранение дерева в `IndexedDB` при отсутствии интернета
- Кнопка «Скачать всё для работы без интернета» и обновление прогресса/статуса

## 2. Ручные тестовые сценарии (перед демо)

### Сценарий A · Основной путь (онлайн)
1. Открыть карту Актау → видны 8 демо-деревьев.
2. Нажать на дерево → открывается паспорт (вид, высота, состояние, бейдж `Демо`, задачи).
3. Нажать **«+ Дерево»**, загрузить фото → нейросеть предлагает 3 варианта вида с процентами.
4. Нажать **«Моё местоположение»** → подставляются GPS-координаты → сохранить → дерево сразу появляется на карте.
5. В паспорте добавить задачу **«Полив»** с фото «до», затем завершить её с фото «после».

### Сценарий B · Полевая работа без интернета (авиарежим на телефоне)
1. Нажать **«Скачать офлайн»** → **«Скачать всё для работы без интернета»** → дождаться 100% и статуса **«Офлайн готов»**.
2. Включить **Авиарежим** на телефоне (бейдж меняется на `Офлайн`).
3. Двигать и приближать карту Актау — закешированные фрагменты отображаются без сети.
4. Нажать **«+ Дерево»**, выбрать фото → нейросеть в телефоне выдаёт 3 варианта вида без интернета.
5. Нажать **«Сохранить в телефон (офлайн)»** → дерево появляется на карте с пунктирной рамкой, счётчик ожидания становится `(1)`.
6. Выключить **Авиарежим** → через несколько секунд дерево автоматически отправляется на сервер без дубликатов.
